One single-line joke giving an excuse for missing a deadline, written to `/output/entry.txt`. The excuse is the excuse-writing itself: the speaker spent so long crafting the perfect excuse that the deadline slipped by while they were at it — a self-referential loop with the punch on the last word, in the voice of someone cornered. No dog, no dead Wi-Fi, no crashed laptop.

> I spent so long writing the perfect excuse for missing the deadline that I missed the deadline.

## Run it

```sh
python3 main.py
```
